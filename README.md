Device Tree for EEBBK A2/X2/X2 Pro (P22H190)
==========================================

The EEBBK A2/X2/X2 Pro (codenamed _"P22H190"_) is a learning tablet from EEBBK.
It was released in November 2022.

| Basic                   | Spec Sheet                                                                                                                     |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (2x2.0 GHz Cortex-A75 & 6x1.8 GHz Cortex-A55)                                                 |
| Chipset                 | Unisoc Tiger T610 (12 nm)                                                                                       |
| GPU                     | Mali-G52 MP2                                                                                                                   |
| Memory                  | 4/6 GB RAM                                                                                                                     |
| Shipped Android Version | 11.0                                                                                                                           |
| Storage                 | 128/256 GB                                                                                                                    |
| Battery                 | Non-removable Li-Po 5000 mAh battery                                                                                           |
| Display                 | IPS LCD 60Hz                               |
| Camera (Back)(Main)     | 8 MP                                                                                 |
| Camera (Front)          | 5 MP                                                                                                                          |
